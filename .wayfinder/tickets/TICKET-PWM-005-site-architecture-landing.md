## Question

What should the PWM website's structure be? Propose:

- **Landing page**: what the visitor first sees — the README wants a landing page where you can navigate to either the lessons or the presentation. Sketch the sections (title, tagline, links/cards to Lessons and Presentation, maybe a teaser widget).
- **Lessons index**: since lessons aren't interconnected and there's no index, propose the index page and the navigation pattern between lessons (prev/next, breadcrumb, "back to index").
- **Routing/site map**: the full page list (landing, lessons index, each lesson, presentation entry, reference/cheat sheet) and how they link.
- **Where the presentation fits**: embed it in the site vs. link out — consistent with the component-sharing decision.

Deliverable: a rough wireframe/prototype (HTML mockup or outline via the `/prototype` skill) plus a written site map. React to the mentor's feedback and converge on the structure the build plan will describe.
